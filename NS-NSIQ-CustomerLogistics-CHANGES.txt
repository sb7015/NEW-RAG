1. CORRECTIONS TO THE ORIGINAL EXPORT
-------------------------------------
1.1 QA - Amazon EC2 (10 x m5.4xlarge)
    Original: labelled On-Demand but priced at $4,117.20, which is the
              1-yr Compute Savings Plan rate ($0.564/hr).
    Final:    On-Demand, $5,606.40.
    Why:      The cost did not match its own setting. The setting was kept
              and the cost corrected.

1.2 Prod - Amazon DocumentDB (3 x db.r6g.2xlarge)
    Original: $1,215.45, which is roughly the db.r6g.xlarge price.
    Final:    db.r6g.2xlarge, $2,305.19.
    Why:      Cost did not match the stated instance type.

1.3 Prod - Amazon Textract
    Original: 50,000 pages/month (lower than Dev 125,000 and QA 60,000).
    Final:    300,000 pages/month, $7,732.50.
    Why:      Likely data-entry error. 300,000 = 5 x QA, the same ratio
              the other Prod workloads use (Bedrock requests, AgentCore
              sessions). ASSUMPTION - confirm the real volume.


2. CHANGES FORCED BY THE CALCULATOR
-----------------------------------
2.1 Elastic Load Balancing (all groups) - OPEN ITEM
    Original: Dev $300, QA $250, Prod $800 for 2 ALBs each.
    Final:    $32.97 per group.
    Why:      The export only contained the ALB count, not the traffic
              (LCU) settings that drove the original cost. The calculator
              will not save without one traffic value, so a near-zero
              placeholder of 0.01 GB/hour was entered.
    Action:   Provide real traffic figures; the true cost is closer to
              the original ($1,350/month across all groups).

2.2 Amazon Bedrock - Claude Sonnet 4.5 and Haiku 4.5
    Why:      The calculator now takes "requests per minute x hours per
              day" (whole numbers only) instead of "requests per month".
              Monthly volume = rpm x hours x 60 x 30, so some volumes had
              to be rounded to the nearest possible value.

2.3 Amazon OpenSearch Service
    Original: summarised as "Number of nodes: 4" (Dev/QA) and "6" (Prod).
    Final:    Dev/QA = 1 data + 3 dedicated master (r5.2xlarge.search)
              + 2 UltraWarm (ultrawarm1.large.search). This reproduces the
              original $6,082.36 exactly.
              Prod = 3 data + 3 dedicated master + 2 UltraWarm = $7,167.14.
    OPEN ITEM: Original Prod cost was $12,164.72 (exactly 2x Dev). If Prod
              is meant to be a doubled domain, it should be raised.

2.4 NAT Gateway (Amazon VPC)
    Added:    "Data processed per Regional NAT Gateway" = same GB as the
              standard NAT gateway (Dev 1,000 / QA 800 / Prod 3,000 GB).
    Why:      Not in the export, but this value reproduces the original
              NAT cost to the cent in all three groups
              (664.20 / 610.20 / 2,007.00).

2.5 AWS CloudTrail
    Original: volumes shown only as "millions".
    Final:    S3 data events = 3 / 1.5 / 6 million per month
              (Dev / QA / Prod); 1 management trail (first copy free).
    Why:      These values reproduce the original costs exactly
              ($3.00 / $1.50 / $6.00).
